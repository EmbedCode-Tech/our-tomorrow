# Our Tomorrow ❤️

A premium cinematic love-story website designed for GitHub Pages.

## Folder structure

```text
our_tomorrow/
├── index.html
├── style.css
├── script.js
└── images/
    ├── hero.jpg
    ├── photo1.jpg
    ├── photo2.jpg
    ├── photo3.jpg
    └── photo4.jpg
```

## Add your photos

Create an `images` folder and put your photos inside it.

Recommended:
- `hero.jpg` — your best couple photo
- `photo1.jpg` through `photo4.jpg` — your memories

The gallery placeholders can also be converted to real `<img>` elements later.

## Publish on GitHub Pages

1. Create a new GitHub repository, e.g. `our-tomorrow`.
2. Upload `index.html`, `style.css`, `script.js`, and the `images` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide your website URL.

## Personalize

Search `Mrunal` or `Rohit` in the files if you want to add names in more places.

For the most personal version, replace the text with your real memories, inside jokes, dates, favorite foods, places you visited, and your own photos.
